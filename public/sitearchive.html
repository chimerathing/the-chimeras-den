LAYOUT ARCHIVE!

A timeline of all of the ways my site has looked! well, how the homepage has looked at least.

CHIMERATHING V1 : DRAGON'S BLOOD
(September 29th, 2024 - Febuary 8th, 2025)

the very first ever layout of my site! it's so ugly i hate it and this is the only screenshot i could find of it at all LMFAO its from very early on. i tried looking on the wayback machine for a later version of it but there's only one snapshot from when it looked like this and none of the images load. i still had very little html/css knowledge back then so i couldnt make it look as great as i wanted. i felt very restricted by how small the layout was but i stuck with this layout for a while for some reason LMFAO i guess i was just too lazy or scared to experiment more. it looks so bland and the color palette is so dull idk how i survived

CHIMERATHING V2 : POMEGRANATE JUICE
(Febuary 8th, 2025 - August 21th, 2025)

second ever layout! i don't hate this one (not as much at least) but it still felt incredibly bland. this was when i finally allowed myself to experiment with the layout a little more but i still barely knew how to do anything properly so everything was jank as fuck lmfao. i spent a lot of time trying to fix shit and make it more interesting to look at. as well as more accessible. i also switched from a Falin Touden theme to a Kasane Teto theme because I'm not as fixated on dunmeshi as I once was unfortunately

CHIMERATHING V3 : RED VELVET
(August 21th, 2025 - May 15th, 2026)

this is definitely one of my favorite layouts so far!! the V2 layout layed the foundation for this one quite a bit. i decided to really push myself to make it look as good an organized as possible. the code for this was still a bit of a mess but i tried my best to clean it up lol. i felt like i still was really restricting myself by continuing to use sadgrl's template though so into the trash it went so i could try something new!
